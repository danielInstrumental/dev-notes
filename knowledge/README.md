# Knowledge

Reference material I look things up in — concepts, the ways systems fail, how to test. Project-neutral
and written to be read on its own. The kit's skills draw on these files (installed into a project at
`.claude/knowledge/`), but nothing here is an instruction.

| File / folder | What it is |
|---|---|
| [`concepts/`](concepts/README.md) | The concepts map — engineering vocabulary by family, one line per term — plus own-words deep dives by topic |
| [`bug-classes.md`](bug-classes.md) | The ways systems go wrong: symptom → class name → standard mitigations |
| [`testing.md`](testing.md) | Every kind of test and the growth ladder (coverage → property-based → mutation → integration → E2E → CI) |
