# Knowledge

Reference material I look things up in — concepts and the ways systems fail. Project-neutral
and written to be read on its own. The kit's skills draw on these files (installed into a project at
`.claude/knowledge/`), but nothing here is an instruction.

| File / folder | What it is |
|---|---|
| [`concepts/`](concepts/README.md) | The concepts book — engineering vocabulary organized like a reference book: 5 parts, 16 chapters, one file each. Every term gets one line; my own-words explanations sit in the same chapter |
| [`bug-classes.md`](bug-classes.md) | The ways systems go wrong: symptom → class name → standard mitigations |
